# Circle - 你的生活伙伴

> 面向所有人的生活助手，优先关注并解决在传统产品设计中被忽略的女性视角与需求。

**👩‍💻 独立开发 | 6 大功能模块 | 单次对话成本 < 0.01 元 | 已支持用户记忆**

🌸 **核心理念**：好的产品设计应该看见每一个人。Circle 从女性视角出发，覆盖烹饪、清洁、健康护理与情绪关怀四大生活场景，同时对所有用户保持开放与温暖。


## 🎯 项目背景

市面上的生活助手类产品往往采用"通用默认"的设计思路，而这个"默认"通常不自觉地向男性视角倾斜。例如：

- 健康建议默认以男性生理为基准，忽视女性特有的健康需求（经期护理、非典型心脏病症状、盆底健康等）
- 家务建议默认执行者是"主妇"，而非引导全家人共同分担
- 安全功能很少考虑女性可能面临的特殊风险场景

**Circle 试图做出改变**——在保持对所有用户友好的前提下，主动纳入被忽略的视角，提供真正贴心的生活陪伴。

**我做了什么**：从 0 到 1 独立完成了产品定义、交互设计、前后端开发、知识库构建和成本优化，形成了一个可演示的完整产品。


## ✨ 核心功能

| 模块 | 内容 | 产品思考 |

| ✨ **清洁与收纳** | 分区域清洁妙招（厨房/衣物/全屋）、收纳原则、懒人维护法则、引导家人分担 | 在建议中主动加入"如何引导家人共同维护"的维度，体谅隐形劳动 |

| 💬 **情绪与安全** | 情绪疏导、经前心理关怀、健康边界建立、家庭暴力识别与求助渠道 | 内置张桂梅、伍尔夫、李清照等女性人物语录，在对话中自然融入鼓励 |

## 🏗️ 技术架构

```text
用户浏览器 (index.html)
│ POST /api/chat
▼
Flask 后端 (app.py)
│
├─ 0. 加载用户记忆 (memory/user_memory.json)
│ └─ 获取用户称呼、偏好、健康信息，拼入 System Prompt
│
├─ 1. 关键词匹配检索知识库 (knowledge/*.json)
│ └─ 返回最相关的 2-3 条知识条目
│
├─ 2. 拼接 System Prompt + 用户记忆 + 知识条目 + 对话历史
│
└─ 3. 调用 DeepSeek API (单次调用)
└─ 返回回复给前端
```

### 技术选型

- **后端**：Python 3.10+ / Flask
- **前端**：单个 HTML 页面（内嵌 CSS + JS），无额外框架依赖
- **AI 模型**：[DeepSeek](https://platform.deepseek.com)（`deepseek-chat`）
- **知识库**：3 个 JSON 文件，共 55 条精心编撰的生活知识条目
- **检索策略**：关键词匹配 + N-gram 子串打分，零额外依赖
- **记忆存储**：本地 JSON 文件，跨会话保留用户信息

### Token 优化设计

- System Prompt 固定在 `role: system` 位置，充分利用 DeepSeek 上下文缓存
- 对话历史仅保留最近 8 轮
- 知识库按需检索，每次仅拼接最相关的 2-3 条（而非全量加载）
- 每轮对话仅 1 次 API 调用，精简高效


## 📊 量化成果

- **成本控制**：单次对话平均消耗 ~400 Token，成本 < 0.01 元
- **知识覆盖**：55 条生活知识，覆盖烹饪、清洁、健康 3 大场景
- **用户记忆**：跨会话记住用户称呼、饮食偏好、健康信息，实现个性化对话
- **交互体验**：思考提示语（按主题切换）、打字机效果、移动端适配
- **工具能力**：免费接入 DuckDuckGo 联网搜索；支持 6 种文件格式（TXT / PDF / DOCX / MD / XLSX / PPTX）


## 🎨 设计原则

1. **视角公平** — 主动识别并优先考虑女性视角，健康建议区分"正常不适"与"就医信号"
2. **体谅隐形劳动** — 家务建议包含家人分工引导，不默认某一方的责任
3. **尊重与安全** — 提供冷静清晰的求助渠道，认真对待每一种不安全感
4. **循证为本** — 健康建议基于科学证据，明确标注信息来源的可靠程度


## 🚀 快速开始

### 1. 环境准备

```bash
# 克隆项目
git clone [你的仓库地址]
cd circle

# 创建虚拟环境（推荐）
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置 API Key

在 [DeepSeek 开放平台](https://platform.deepseek.com) 注册并获取 API Key，然后设置系统环境变量：

**Windows（PowerShell）：**

```powershell
# 永久生效（推荐）
[System.Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "sk-你的Key", "User")
# 设置后需要重启终端生效
```

**macOS / Linux：**

```bash
echo 'export DEEPSEEK_API_KEY="sk-你的Key"' >> ~/.zshrc
source ~/.zshrc
```

环境变量方式不会将密钥存储在项目文件中，完全避免误提交的风险。

### 3. 启动服务

```bash
python app.py
```

浏览器访问 http://localhost:5000，开始和 Circle 对话 🌸

## 📝 开发笔记

- 知识库内容参考公开的医学资料与生活百科编撰，**不构成专业医疗建议**。如有健康问题请咨询执业医师
- 知识库条目的 `keywords` 字段直接影响检索效果，扩展知识库时请注意关键词覆盖
- 如需修改回答风格，调整 `app.py` 中的 `SYSTEM_PROMPT` 即可
- 用户记忆存储在 `memory/user_memory.json`，可手动查看或清理
